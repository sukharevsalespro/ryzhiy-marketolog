# План реализации: нетворкинги в календаре и страница /networking/

**Ветка**: `001-networking-events` | **Дата**: 2026-09-26 | **Спека**: `specs/001-networking-events/spec.md`

## Кратко
Один файл данных `assets/data/events.json` → календарь главной рендерит месяцы/выделения/карточку из него (код листания в `main.js` уже есть, меняем только источник событий). Новая статичная страница `/networking/` по шаблону внутренних страниц (`/webinar/`), с JSON-LD `Event` ×3, OG, sitemap, llms.txt. Сверка копий данных — маленький node-скрипт.

## Технический контекст
- Статика на GitHub Pages за nginx BTC, без сборки. Vanilla JS (ES5-стиль, как `main.js`), CSS сайта.
- CSP на страницах: `script-src 'self' https://mc.yandex.ru`, `connect-src 'self' …` — `fetch('/assets/data/events.json')` проходит, инлайн-скрипты нельзя (JSON-LD — не исполняется, можно).
- Проверки: node (скрипт сверки), headless Chrome через CDP.
- **Предзаполнение мессенджеров (не проверено, проверить в T005):** Telegram — `https://t.me/<username>?text=<urlencode>`; поддержку для личного чата подтвердить на живом клиенте (iOS/Android/Desktop/Web). MAX — механизм подстановки текста неизвестен; искать в документации MAX, иначе фолбэк «копировать в буфер + тост + открыть чат».

## Проверка конституции
- Не угадывать: время прошедших нетворкингов, платформа, выбор контактов — вопросы владельцу, дефолты в спеке помечены. ✅
- Дизайн через референсы: при вёрстке — Refero MCP + `refero-design`, `ui-ux-pro-max`, эталон-постер. ✅
- Шрифты самохост, новых не добавляем. ✅ Рукописи только существующие. ✅
- Выкатка только после скриншотов и «ок». ✅
