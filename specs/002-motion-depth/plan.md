## Токены (черновик, уточняются на макете)
```css
:root{
  --plate: #000;            /* оттиск на рыжем, креме, синем; на чёрном — var(--cream) */
  --plate-off: 3px;         /* смещение при ховере */
  --press: 1px;             /* посадка при нажатии */
  --ease: cubic-bezier(.2,.7,.2,1);
  --t-tap: 90ms; --t-state: 200ms; --t-enter: 600ms; --stagger: 60ms;
  --glass-cream: rgba(250,247,242,.72); --glass-ink: rgba(0,0,0,.72); --glass-blur: 14px;
}
```
Плашка — псевдоэлемент `::before` с `inset:0`, `z-index:-1`, двигается `transform`, а не `box-shadow` (тень анимировать дороже и на ней не сделать «посадку»). Кнопке нужен `isolation:isolate`, чтобы `z-index:-1` не ушёл под фон полосы.

## Ключевые решения и почему
| Решение | Источник | Почему |
|---|---|---|
| Глубина через сплошной оттиск второй краски, без размытия | Album Colors `99be9294`, Pop Manifesto `137e85e2`, Fidèle `d8496f36` (все: «no shadows, 0px radius»); ui-ux-pro-max Neo Brutalism «mechanical press» | постерный язык запрещает мягкие тени; оттиск читается как печать, а не свет |
| Плашка скрыта в покое | эталон-постер | покой = постер 1:1, глубина появляется только в отклике |
| Шапка А как рекомендация | эталон (имя слева, меню справа), OpenWeb `4ba1eb9b` | ближе к эталону; Б — альтернатива на макете |
| Мобильное меню полноэкранным `<dialog>` | Nothing `5e52ffa8`; уже есть нативный `<dialog>` в лайтбоксе отзывов | Esc, фокус-ловушка и возврат фокуса без библиотек |
| Без GSAP/Motion/Aceternity | gsap-framer-scroll-animation (GSAP нужен для pin/scrub), framer-motion и aceternity — React | pin/scrub не делаем, React нет, CDN запрещён; WAAPI + IO уже в `main.js` |
| Параллакс через `animation-timeline: view()` | impeccable animate, design-taste-frontend 5.D (запрет scroll-listener) | нулевой JS; без поддержки — статичное фото, постер не ломается |
| Маска параллакса на обёртке, не на `img` | ui-animation (конфликт владельцев transform) | у `.hero-media img` уже есть `transform` (мобилка `translateY(-5%)`) и вход `photo` |
| Рукопись вытирается построчно | факт: `hand-bolshe.svg` = один залитый `<path>` (проверил) | `stroke-dashoffset` для заливки potrace не рисует письмо |
| Активный пункт и `is-stuck` через IntersectionObserver | design-taste-frontend 5.D | без `scroll`-обработчиков |

## Риски
- Трекинг Poster-заголовков: маска строки не должна менять `letter-spacing` и перенос (грабля БЗ с Fira). Проверять пробелы в заголовках секций после правки.
- Постерная раскладка на `rem` от вьюпорта (D33): плашка и параллакс не должны двигать абсолютно спозиционированные подписи «Форматов». Трогать только `transform` внутри своих элементов.
- Стекло над фото: контраст меню ломается на светлых участках снимка — мерить худшую точку, при провале стекло плотнее (.85).
- Снимки CDP виснут на непрерывных анимациях (грабля БЗ) — на время кадров глушить анимации, для видео — отдельный прогон без глушения.
- `hidden` не прячет элемент с `display:flex` (грабля БЗ) — для мобильного меню использовать `<dialog>`, не `hidden`.
