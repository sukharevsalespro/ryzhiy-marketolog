## 4. Шапка и подвал (T003)

Сверил разметку построчно с главной (скрипт в scratchpad, `diff` по тегам):
- **Шапка** одинаковая везде. Отличаются только якоря меню: у главной `#about`, `#formats`, `#calendar`, `#thoughts`, у остальных `/#about` и т.д. Это правильно.
- **Нашёл дефект (не правил):** у мастер-группы в шапке якоря как у главной (`#about`, `#formats`, `#calendar`, `#thoughts`), а таких `id` на странице нет. Проверил grep: у мастер-группы 0 из 4, у главной 1 из 1 по каждому. Клик по «Обо мне», «Календарь», «Блог», «Все форматы» на мастер-группе никуда не ведёт. Фикс в одну строку: заменить на `/#…`. Нужно «да».
- В 404 пункт меню подписан «Мастер-группа по личному бренду», у остальных — «Мастер-группа». Выровнять при волне 5.
- **Подвал** везде одинаковый по содержимому. У главной и мастер-группы обёртка `page-band--black nb-foot nb-foot--f1`, у остальных `page-band--black`. Классы `nb-foot*` не используются ни в одном CSS/JS (grep = 0), визуальной разницы нет.

## 5. Решение по CSS (T004)

- Новый файл `assets/css/nd-pages.css`: токены `--nd-*` (роль → значение из §1, обе темы) и компоненты второстепенных страниц. Первый компонент — первый экран `/networking/` (`.nwh`, `.nd-tix`, `.nd-pay`, `.nd-h1`, `.nd-kick`, `.nd-back`).
- Порядок подключения на переведённой странице: `style.css` → `mobile.css` → `footer.css` → `home-blocks.css` (оттуда берутся `--nb-graphite` и `--nb-noise`, файл целиком подключается, а не копируется) → нужные файлы главной (`reviews.css`, `formats.css`) → `nd-pages.css`.
- Body переведённой страницы: `home nd <slug>`. Проверил на макете: правила `.home` не ломают первый экран. Шкала rem у `.home` (≥1280 → 2px) на `nd-pages.css` не влияет: там px и clamp, как у мастер-группы.
- Старые `networking.css`, `landing.css`, `webinar.css`, `utility.css` не трогаю до последней волны.
- Долг: `.nd-pay` повторяет `.mg-pay` с токенами `--nd-*`. Свести в один компонент — волна 6 (иначе два источника одной кнопки, см. реестр 26.09).
