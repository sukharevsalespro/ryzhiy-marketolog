# Ryzhiy-Marketolog Constitution

## Core Principles

### 1. Роли и делегирование
Код правят только через явно поставленные подзадачи/сабагентов; крупные архитектурные и дизайнерские решения — по согласованию с владельцем, самовольно не менять. Каждое утверждение в отчётах — с пометкой источника (проверил / со слов / не знаю); цифры (цены, сроки) без проверенного источника не называть.

### 2. Не угадывать, не делать лишнего
Неоднозначное требование — переспросить конкретный вариант, не выбирать молча. Ничего не выдумывать: нет данных (цены, имена, даты, отзывы) — спросить у владельца, а не подставлять правдоподобное. Правится ровно то, что попросили, без побочных правок.

### 3. Дизайн только через референсы
Любая вёрстка/дизайн — сначала Refero MCP + профильные дизайн-скилы (ui-ux-pro-max и т.д.), вёрстка только после ресёрча, не на глаз. Эталон стиля — главная (`/`) и `/master-gruppa-lichnyj-brend/` нового дизайна (решение владельца 01.10.2026): второстепенные страницы берут их дизайн-систему (шрифты, цвета, плашки, кнопки, радиусы, стекло, анимации, шапка/подвал, две темы — светлая и тёмная), композиция и первый экран — свои. `docs/reference-poster.jpg` — исходник, из которого вырос стиль, эталоном больше не служит.

### 4. Шрифты и контент — без самодеятельности
Шрифты только самохост (Roboto Condensed, Golos Text и т.п.), без внешних CDN. Отзывы клиентов публикуются дословно, без редактуры — оригиналы как есть.

### 5. Проверка перед выкаткой
Сайт обязан выглядеть нормально на всех устройствах: матрица от 3840 до 320px, планшеты, альбомная ориентация, зум. Не выкатывать, не посмотрев скриншоты самому — пустой подвал и склейку ссылок уже ловили из-за выката по одному отчёту агента.

## Инфраструктурные ограничения

Тяжёлый апскейл изображений — только на домашнем ПК владельца (RTX 5060) через reverse SSH, не на сервере (сервер слабый). Прод — GitHub Pages из ветки main за nginx BTC; публикация только после явного «ок» владельца.

## Governance

Конституция главенствует над умолчаниями агента. Любое отступление от принципов — явное решение владельца, зафиксированное в БЗ проекта (`/root/knowledge-base/projects/ryzhiy-marketolog.md`) или в `docs/OWNER-REQUESTS.md`. При правках сверяться с БЗ проекта как источником истины.
