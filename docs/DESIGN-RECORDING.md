# Страница записи «Маркетинг Доверия»

Reference lock: принятая главная, постерный вебинар и реальная афиша владельца. Сохранены #FE6C1F / #1F7EFC / кремовый / чёрный, Roboto Condensed 900, Golos, прямые углы и единое полотно1320px. Из ресёрча Refero, записанного в DESIGN-SHARING.md: крупная типографика и прямоугольное изображение как самостоятельный контент. Афиша не перекрашена, не обрезана и не перегружена эффектами. Landing-page-design использован для близости CTA к описанию ценности и повторного действия после программы; выдуманные социальные доказательства не добавлены.

Композиция: название и покупка слева, афиша справа; ниже точная подводка, программа2×2, одна синяя полоса с фразой о бонусах, автор с новым крупным портретом, финальная покупка. На мобильных — одна колонка; афиша целиком и ссылка на её увеличенную версию для мелких надписей.

Кроп автора: из исходника720×1280 взята область (100,200)–(700,1000),600×800; экспорт600×800 и1200×1600WebP. Версия1200 — увеличение исходного кропа для requested srcset, новых деталей оно не создаёт. Афиша экспортирована целиком600×1067 и1200×2133; пропорции сохранены с округлением до пикселя.

Текст: исключительно присланные владельцем название, описание, четыре пункта, бонусная строка и доступ после оплаты. Цена и сроки доступа не указаны. Строка «Бонусы для всех онлайн-участников» не превращена в обещание состава бонусов покупателям записи; этот состав требует уточнения.

- Нужно ли указать вторую спикершу и как её зовут? На афише две ведущие; имя второй не добавлено.
- Мелкая отметка «02 / 2025» на афише видна, но 18 августа2025 — понедельник, а крупно написано «ВТОРНИК». Дата отдельной строкой на странице не добавлена: назначение мелкой отметки неоднозначно. Подтвердить дату при необходимости её публикации.
- Какие бонусы получает покупатель записи? Пока сохранена только исходная фраза об онлайн-участниках.
