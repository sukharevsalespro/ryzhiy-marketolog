# Отзывы клиенток — источник правды

15 живых отзывов из переписок (Telegram / WhatsApp), присланы владельцем 24.09.2026.
Тексты перенесены со скриншотов **дословно**, с авторской пунктуацией и опечатками.
Эмодзи в расшифровке опущены, слова — нет. Править тексты нельзя: это первоисточник.

На сайте расшифровки НЕ выводятся — там сами скриншоты. Этот файл нужен для
подписей под карточками, для alt-текстов картинок и для любых будущих материалов.

## Правила подписей

- Автор указывается **только если он реально виден на скриншоте** (ник/имя в шапке
  сообщения или обращение Валентины в ответе). Имена не додумываем.
- Где имени нет — обезличенная подпись, выведенная **только из текста самого отзыва**
  («участница обучения», «участница групповой работы»). Профессии не выдумываем.
- Валентину в отзывах зовут «Валя», «Валечка» — оставлено как есть, это живая речь.
- Продукт указывается, только если он назван или однозначно следует из текста.
  Иначе — «не указано».
