# Дизайн-решения сайта «Рыжий маркетолог»

Исследование: Refero MCP — `refero_search_styles` («bento grid personal brand portfolio warm photography»),
`refero_get_style` по трём отобранным владельцем стилям, `refero_search_screens`
(«bento grid personal site about me tiles», «webinar registration landing page date time price»).

## Reference lock

**Primary — Portrait (portrait.so, `0a8a4374…`)** — композиция.
Сохраняем: контейнер до 1200px, плитки-карточки с радиусом 24px, многослойная мягкая тень
низкой непрозрачности (не одна системная), фото живут внутри скруглённых плиток с внутренним
паддингом, сетка из плиток разного размера вместо одинаковых колонок.

**Secondary — Monarch (`d1af3fe4…`)** — типографика и дисциплина акцента.
Берём только: овсяный фон-канвас + светлые карточки поверх, сериф-заголовки лёгкого начертания
(«авторитет без крика»), пилюльные кнопки 9999px, волосяная линия-бордер, section gap 64px,
правило «рыжий — только для CTA и ключевых акцентов, никогда для текста и больших фонов».

**Tertiary — mymind (`3473a05f…`)** — свет в hero.
Берём только: радиальное тёплое свечение как фон hero-плитки (по правилу источника — только hero,
никогда фон карточки или заливка кнопки), eyebrow-подписи капсом с положительным трекингом
+0.16em в акцентном цвете над серифными заголовками, медленный easing cubic-bezier(.19,1,.22,1).

**Reject:** белый канвас Portrait (у нас сливочный из презентации), радужные градиенты Portrait,
тёмная manifesto-секция mymind, аутлайн-CTA mymind (у нас CTA заливной по правилу Monarch).

## Роли токенов

| Токен | Значение | Роль (не нарушать) |
|---|---|---|
| `--canvas` | `#ECE5DC` | фон страницы |
| `--card` | `#FFFCF8` | поверхность плиток |
| `--ink` | `#1D1815` | основной текст, тёмная плитка |
| `--muted` | `#5F544B` | вторичный текст |
| `--line` | `#C9BDB2` | волосяные границы, разделители |
| `--rust` | `#E0631A` | заливка CTA, маркеры, подчёркивания, иконки. НЕ фон секций, НЕ текст |
| `--rust-ink` | `#A8460F` | акцентный ТЕКСТ (eyebrow, цифры) — затемнён ради контраста 5.19:1 на канвасе |
| `--gold` | `#A07B52` | декоративные линии/рамки |
| `--gold-ink` | `#8A6540` | второстепенные подписи-текст — затемнён ради контраста 4.51:1 |

Контраст: `#E0631A` под белым текстом даёт 3.56:1 (мимо WCAG AA), поэтому CTA — рыжая заливка
с тёмным текстом `--ink` (4.97:1). Ховер осветляет заливку, `:active` не меняет цвет (только сдвиг),
чтобы не провалить контраст.

## Шрифты (самохост, `assets/fonts/`)

| Шрифт | Роль | Откуда |
|---|---|---|
| **Prata** 400 | дисплей/заголовки от 28px, трекинг −0.02…−0.03em | Google Fonts css2, woff2, подмножества cyrillic + latin |
| **Golos Text** 400–700 (variable) | весь UI-текст, подписи, кнопки | Google Fonts css2, woff2, подмножества cyrillic + latin |

Prata — русский по происхождению дидон, закрывает роль «Louize/Copernicus» из референсов
(сериф весом 400 на крупном кегле = масса вместо жирности). Golos Text — кириллический гротеск
вместо дефолтного Inter. Оба с `font-display: swap`.

## Decision ledger

| Решение | Источник | Правило источника | Почему |
|---|---|---|---|
| Бенто 12 колонок с разными пропорциями плиток | Portrait + требование владельца | «сетка плиток разного размера, не колонки» | прямое требование + композиция primary-референса |
| Тёплое свечение только в hero | mymind | «Hero Bloom только на hero-масштабе» | один яркий момент, дальше страница спокойная |
| Тёмная плитка «15+ лет» | mymind (dark manifesto), уменьшено до плитки | тональный разрыв в светлой системе | якорит взгляд, даёт бенто-контраст без второго акцентного цвета |
| Сериф только в заголовках, гротеск в тексте | Monarch | «Copernicus — только заголовки страницы» | доверие/статус без декоративности |
| Заливной рыжий CTA, аутлайн-вторичка | Monarch | «Monarch Flame только для primary action» | у сайта одна цель — написать/занять место |
| Eyebrow-капс с трекингом над заголовками | mymind | «+0.063…0.125em, в акцентном цвете» | ритм и навигация по плиткам |
| Коллаж 6 квадратов «Разные локации, один образ» | Portrait (imagery-led) + CONTENT.md | «фото — обязательный ингредиент, внутри скруглённых плиток» | её собственный визуальный якорь, нельзя заменять текстом |
| Программа вебинара — 6 отдельных плиток | refero_search_screens (webinar landing: multi-card benefits grid) | — | 6 дословных пунктов читаются как сетка, а не как список |

## Отступление от лока (осознанное)

Тёплое свечение mymind по правилу источника разрешено только на hero-масштабе. На странице вебинара
оно применено дважды — в hero и в финальном CTA. Оба — полноширинные секции-плитки, а не карточки
и не заливки кнопок, то есть роль токена сохранена: страница открывается и закрывается одним и тем же
светом. На главной свечение только в hero.
