# Движение: главная и вебинар

## Reference lock

Бренд и принятая композиция остаются источником геометрии. Refero: запрос `motion editorial poster landing`, затем полные стили [Made With GSAP](https://refero.design/styles/a688c0a5-e49d-4bc1-b8c9-66e19ad90dd7) и [Figma Config](https://refero.design/styles/bb8e48ab-b4f8-4b66-8796-206b512af8d6).

- Made With GSAP: типографика как главный акцент, чередование плотных контрастных модулей. Адаптация: строки заголовка появляются последовательно, карточки — небольшим каскадом. Не переносим галерею эффектов, GSAP, неоновую палитру и радиусы.
- Figma Config: прямые кнопки, тонкие линии, прямое переключение контраста. Адаптация: инверсия кнопок, короткое движение стрелки, подчёркивание. Не переносим плавающие/вращающиеся абстрактные формы.
- Это семантические стилевые референсы, а не записи анимаций: конкретные тайминги ниже — наше решение, не измеренные свойства исходных сайтов.

## Скилы

`web-motion-design`: постановка внимания, перекрытие фаз через stagger, ease-out, transform/opacity, временный will-change. `ui-ux-pro-max`: reduced-motion, отсутствие движения layout, короткая обратная связь, ограничение одновременных акцентов. Выполнены design-system и ux-поиск animation accessibility reduced motion. Рекомендации про другие шрифты, таймеры, early bird и новые цвета отвергнуты: задача — движение принятого бренда, без новых коммерческих утверждений. `refero-design` — привязка решений к выбранным референсам.

## Decision ledger до реализации

- Однократное появление содержимого секций: 20 px, 420 ms, cubic-bezier(.2,.7,.2,1); соседние карточки/пункты 70 ms. Фоны секций остаются на месте. Никаких scroll listeners или параллакса.
- Заголовок главной: существующие строки, без пересчёта переносов. Сохраняем исходные transform для эталонной ширины букв. Фото: 1.06 → 1, 700 ms. Последнее ограничение «не дольше 700 ms» приоритетнее ранее предложенных ~900 ms.
- Рукопись: проверен inline SVG .hero-hand — один заполненный path, без отдельного stroke. Открываем всю рукопись слева направо через SVG clipPath; его прямоугольник меняет только transform: scaleX. Контур и наклон не меняем, stroke-dashoffset не используем, поскольку росчерк слит с буквами.
- Числа: короткое появление 94% → 100%, без изменения текста или размеров layout. Никаких промежуточных вымышленных цен/фактов и озвучивания счётчика скринридером.
- Hover 160–220 ms: стрелка +4 px, карточка −4 px, цветное пятно +6 px. Цвет инвертируется без интерполяции: анимируем только transform/opacity. Disabled «Скоро» остаются неактивными. Пункты программы остаются текстом, без фиктивных ссылок.
- Marquee: только синяя формула вебинара, одинаковые копии без разрыва; копия aria-hidden. Линейное непрерывное движение — исключение по длительности по смыслу отдельного требования. Пауза hover/focus, кнопка остановки для touch/клавиатуры; вне экрана движение остановлено. Без JS и reduced-motion исходная формула статична и переносится целиком.
- Календарь: один цикл 600 ms для рамки вокруг 21 (псевдоэлемент, scale/opacity), затем покой.
- Progressive enhancement: без JS всё видно; reduced-motion выключает все анимации и smooth scroll, в том числе при изменении настройки в открытой вкладке. Фокус немедленно раскрывает ожидающий элемент. Will-change только на время активного конечного эффекта, очистка после завершения/отмены.
- Общий движок в main.js используется обеими страницами; локальный webinar/motion.js управляет только формулой. Суммарный добавленный JS ≤ 3 КБ без gzip. Логика формы/endpoint остаётся прежней. Проверки не отправляют POST.

## Проверка готового результата

- Суммарный добавленный JS: 2517 байт (движок, локальный контроллер и два коротких head-фрагмента), без gzip; библиотек и внешних запросов для анимаций нет. Конечные эффекты используют браузерный Web Animations API, без собственного покадрового JS.
- Chromium: обе страницы, 1440 и 390 px, обычный режим / отключённый JS / reduced-motion. Контент виден, ожидающих элементов и оставшегося inline will-change нет, горизонтального скролла нет, console/404/POST — пусто. Повторный проход не увеличивает количество появлений (22 на главной, 24 на вебинаре).
- Отдельно проверены только transform/opacity в keyframes, сдвиг стрелки +4 px, промежуточная маска рукописи, пауза формулы, включение reduced-motion в открытой вкладке. В бесконечной ленте два одинаковых сегмента с одинаковым завершающим разделителем; остановка сохраняет текущую фазу.
- Lighthouse mobile Performance на одинаковом локальном сервере: главная 88 → 86 (−2, допустимый предел −3), вебинар 92 → 93 (+1). Финальные отчёты: shots8/lighthouse-home-final.json, lighthouse-webinar-final.json; базовые — *-before.json. TBT 0 ms обе страницы. CLS: главная 0 → 0; вебинар 0.000201 → 0.000201. Проверка не является гарантией FPS на любом устройстве; новых layout-анимаций и покадровых вычислений нет.
- Итоговые full-page скриншоты после полной прокрутки: shots8/home-desktop.png, home-mobile.png, webinar-desktop.png, webinar-mobile.png. Marquee — единственное непрерывное движение, оно остановлено вне экрана при съёмке.
- Портрет автора: проверены 390, 1440, 1920 px. После визуальной сверки на 1920 позиция исправлена с 28% на 10%, чтобы сохранить причёску и лицо в верхней трети. Исходный JPG и hero portrait-mic не менялись.
