## Что нельзя решить meta-тегом на GitHub Pages

CSP Report-Only не поддерживается через meta. Поэтому добавлена реальная ограничивающая CSP, проверенная в браузере, а не неработающий «отчётный» тег. `style-src` допускает unsafe-inline для существующих стилей/анимаций; `script-src` не допускает unsafe-inline или unsafe-eval.

`frame-ancestors`, X-Frame-Options, HSTS, X-Content-Type-Options для статических файлов, COOP и полноценный Report-Only требуют HTTP-заголовков. В репозитории Pages их задать нельзя: нужен управляемый прокси/CDN либо другой хостинг. Ничего из этого не заявлено как уже включённое на проде.
