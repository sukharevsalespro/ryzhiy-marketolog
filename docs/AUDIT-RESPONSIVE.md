# Адаптив: итоговая матрица

Chromium headless с --no-sandbox, локальный HTTP-сервер, полная прокрутка и ожидание завершения появления элементов/декодирования изображений. 346 комбинаций: семь страниц ×22 размера ×два режима движения, плюс38 проверок главной/вебинара на дополнительных размерах и при эмуляции зума.

Обозначение «✓»: scrollWidth == clientWidth; заголовки/рукопись/кнопки и текстовые диапазоны внутри окна; соседние блоки сетки не пересекаются; изображения загружены и не растянуты; текст кнопок внутри рамок, активные цели ≥44px при тач-ширинах до1194px; секции центрированы на одном полотне min(1320px, ширина окна). Console/pageerror/локальные404/POST отсутствуют. reduced-motion проверен на каждой основной комбинации: содержимое видно, активных анимаций нет.

Фото/лицо, читаемость графики и общий ритм дополнительно проверены по скриншотам и увеличенным кропам. Автоматическая геометрия не оценивает эстетическое качество. Бегущая строка намеренно проходит через границы своей полосы: это не потерянный текст; доступное имя содержит полную формулу, reduced-motion показывает её статично. Проверка — в Chromium, не обещание идентичного рендера во всех версиях браузеров.

## Что исправлено

- Ограничен корневой rem и все full-bleed сетки; фон растянут, содержимое центрировано.
- Добавлена зависимость hero от высоты, условия800/700px для главной и вебинара.
- Рукопись перекрывает край фото на десктопе; мобильный вариант — крупный акцент под фото на общем рыжем поле.
- Исправлены склейки скрытых br, размеры целей нажатия, адаптив ссылок оплаты и документов.
- Собран плотный футер на всех страницах; меню в две колонки на телефоне.
- Карточки записи и vc.ru получили согласованную иерархию; рукопись третьей карточки не пересекает заголовок, обе ссылки записи имеют контрастный общий фон.
- Реквизиты и юридические тексты переносятся естественно; афиша записи не обрезается, плотный портрет автора сохраняет пропорции.

Полный машинный протокол: shots9/matrix-results.json. Снимки каждой строки: `<page>-<ширина>x<высота>.png`; для широких экранов есть также `-canvas.png`, показывающий полотно без полей окна. Низкие вьюпорты: hero-fit-*.png. Ошибок в итоговом прогоне нет; последняя правка CSS предшествует всему этому прогону.

Использованные скилы: refero-design — reference lock для графики и решений; ui-ux-pro-max — адаптив, цели нажатия, фокус, reduced-motion; landing-page-design — иерархия страницы записи и повтор оплаты рядом с условиями; web-motion-design — сохранение принятой хореографии без layout-анимаций; python-best-practices — проверка обработки заявок и тестов. Ресёрч и решения: DESIGN-MOTION.md, DESIGN-WEBINAR.md, DESIGN-SHARING.md, DESIGN-RECORDING.md.
